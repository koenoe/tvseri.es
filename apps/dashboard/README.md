# Dashboard

Internal admin dashboard for tvseri.es, at `dashboard.tvseri.es`. Only users with the `admin` role can sign in. Everyone else is sent to `/unauthorized`.

## Sections

- **Web**: Web Vitals per route and device, with a world map
- **API**: endpoint timings and upstream dependencies
- **AWS**: Lambda and CDN metrics

The data comes from the API's metrics routes, which are aggregated daily by the crons in `infra/metrics.ts`.

## Stack

Vite, React 19, TanStack Router (file-based, in `src/routes`) and TanStack Query, shadcn/ui on Tailwind v4, and Recharts. Auth uses the OpenAuth `dashboard` client, with tokens kept in `localStorage`.

## Development

Run it from the repo root with everything else:

```bash
pnpm dev
```

SST builds `infra/dashboard.ts` and passes in:

| Variable | Purpose |
|---|---|
| `VITE_API_URL` | API base URL (`/_api` locally, proxied by Vite) |
| `API_PROXY` | Vite proxy target, local stage only |
| `VITE_AUTH_URL` | OpenAuth issuer |

Set `DASHBOARD_USE_PROD_API=1` to use the production API and auth instead of your own stage.

`src/routeTree.gen.ts` is generated by the router plugin. Don't edit it.

## Deployment

SST deploys it as a static site on CloudFront, alongside the rest of the infra in CI.
